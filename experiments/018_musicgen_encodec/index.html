MAESTRO · EXPERIMENT 018

A melody-conditioned generator,
and the codec underneath it.

MusicGen-melody (Meta, 2023) is a 1.5-billion-parameter language model over EnCodec audio tokens. It takes a text prompt and, optionally, a reference recording reduced to a chromagram, and generates up to 30 seconds. It has no symbolic input: a melody is given to it as sound. Here it receives the same melodies as experiments 014 and 016, as synthesized guides and as the original recording, with the prompt "solo acoustic grand piano, expressive ballad, no vocals". Each clip is transcribed and its top line aligned to the written melody, the 014 method, and its chroma is compared with the audio it was conditioned on, the 015 method. The text-only clip is graded the same way as a floor: 60% recall and 0.37 chroma is what unrelated piano in the same style scores. MusicGen's piano is dense (top-line precision 15%), so recall is read against that floor, not against 100%. Below the clips, EnCodec alone: the Color Purple recording encoded and decoded at six settings, to show what the token layer keeps before any generation happens.
