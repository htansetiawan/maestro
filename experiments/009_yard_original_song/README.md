## Reproduce

With the existing pinned runtime and local model snapshots installed:

```sh
/tmp/maestro-yue2/.venv/bin/python experiments/009_yard_original_song/record/generate.py --output-name another-run
python3 experiments/009_yard_original_song/record/build_delivery.py
```

The generator requires a fresh destination. The delivery builder reads the canonical
`outputs/original` result. Exact native token arrays and acoustic latents are retained
locally and excluded from Git; native manifests still reference those local arrays.
Audio, lyrics, score, request, settings, and measurements are published. Model weights
remain in the shared model cache.
